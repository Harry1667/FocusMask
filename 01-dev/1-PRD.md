# FocusMask — Chrome 擴充程式 PRD

**版本**：v0.1  
**日期**：2026-04-28  
**狀態**：草稿

---

## 一、產品概述

FocusMask 是一款 Chrome 瀏覽器擴充程式，透過黑色遮罩封鎖分心網站，幫助使用者在不同情境下維持專注、休息或深度工作狀態。

### 核心價值主張
- **零干擾**：封鎖除白名單外的所有網站
- **多模式**：對應工作、睡前、深度專注、番茄計時等不同場景
- **輕量操作**：點一下按鈕即可啟動／停止

## 三、功能模式規格

### 3.1 專注模式（Focus Mode）

**觸發**：手動點擊「開始專注」按鈕  
**結束**：手動點擊「停止」或設定計時結束（選填）

**行為**：
- 啟動後，非白名單網站一律顯示黑色遮罩
- 遮罩上顯示：目前模式名稱、已專注時間、停止按鈕
- 白名單網站正常顯示，不受影響
- 支援選填：設定專注時長（例如 60 分鐘後自動停止）

**白名單**：每個模式各自獨立設定

---

### 3.2 睡眠模式（Sleep Mode）

**觸發**：使用者設定時間區間，時間到自動啟動  
**結束**：到達結束時間自動解除，或使用者手動停止（需輸入確認密碼，防止自己偷關）

**行為**：
- 在設定的時段內（例如 23:00 ～ 06:00）自動啟動遮罩
- 非白名單網站顯示黑色遮罩，遮罩顯示：「睡眠時段，請休息」、剩餘時間
- 每天自動循環（可設定啟用／停用特定日期）
- 可設定「解鎖需密碼」以避免睡眠時段被手動關閉

**白名單**：獨立設定（例如允許 Spotify、YouTube Music 播放睡眠音樂）

---

### 3.3 沉浸模式（Immersion Mode）

**觸發**：使用者在目標網頁按下「進入沉浸」  
**結束**：僅能手動停止（手動點擊 popup 的「退出沉浸」）

**行為**：
- 鎖定使用者只能使用當前指定的單一網域（例如 notion.so）
- 離開該網域即觸發遮罩
- 遮罩顯示：「沉浸模式中，請返回工作」、返回按鈕
- 可設定是否允許同網域下的子頁面（例如 notion.so/* 全部允許）

**白名單**：以指定的沉浸網域為核心，可加入少數輔助網站

---

### 3.4 番茄鐘模式（Pomodoro Mode）

**觸發**：手動啟動，設定番茄時長與休息時長  
**結束**：一組番茄完成後，詢問是否繼續下一組

**行為**：
- 預設：25 分鐘專注 + 5 分鐘休息（可自訂）
- 專注期間：非白名單網站顯示遮罩
- 休息期間：解除遮罩，顯示休息倒數計時通知
- 完成 4 組後，建議長休息（預設 15 分鐘）
- 每組番茄完成後，桌面通知提醒

**白名單**：獨立設定

---

## 四、黑色遮罩規格

所有模式的遮罩行為一致：

| 項目 | 規格 |
|------|------|
| 遮罩顏色 | 純黑 `#000000`，覆蓋整個 viewport |
| 遮罩層級 | `z-index: 2147483647`（最高層） |
| 顯示資訊 | 模式名稱、剩餘/已用時間、停止按鈕 |
| 動畫 | 淡入 0.3s |
| 例外 | 白名單網站不注入遮罩 |
| 防止繞過 | 遮罩無法被網頁本身的 CSS 覆蓋（Shadow DOM 實作） |

## 五、Popup UI 規格

點擊 Chrome 工具列圖示後開啟 Popup（320px × 480px）：

```
┌─────────────────────────┐
│  🎭 FocusMask           │
│  ─────────────────────  │
│  [目前狀態：閒置]        │
│                         │
│  ┌───────┐ ┌─────────┐  │
│  │ 專注  │ │ 睡眠    │  │
│  └───────┘ └─────────┘  │
│  ┌───────┐ ┌─────────┐  │
│  │ 沉浸  │ │ 番茄鐘  │  │
│  └───────┘ └─────────┘  │
│                         │
│  [⚙ 設定]               │
└─────────────────────────┘
```

- 啟動中的模式以高亮色標示
- 點擊模式按鈕 → 展開該模式的快速設定面板
- 「設定」開啟完整設定頁面

## 六、設定頁面規格

| 區塊 | 內容 |
|------|------|
| 白名單管理 | 每個模式各自的允許網站清單，支援新增／刪除／匯入匯出 |
| 睡眠模式排程 | 時間設定、每週哪幾天啟用、解鎖密碼 |
| 番茄鐘設定 | 專注時長、短休息、長休息、自動開始下一組 |
| 通知設定 | 啟用／停用桌面通知、通知音效 |
| 資料管理 | 匯出設定、重置所有設定 |

```json
  "activeMode": null,

    "sound": true
  }

```

## 八、技術架構

| 元件 | 技術 |
|------|------|
| Manifest | MV3（Manifest V3） |
| Background | Service Worker |
| Content Script | 注入遮罩到所有頁面 |
| Popup | HTML + CSS + Vanilla JS（或 React） |
| 設定頁 | `options_page` |
| 時間排程 | `chrome.alarms` API |
| 跨頁狀態同步 | `chrome.storage.onChanged` |

---

## 九、邊界情況與防繞過機制

- 使用者開新分頁 → content script 立即注入遮罩
- 使用者重新整理頁面 → 遮罩立即重新注入
- 使用者停用擴充程式 → 遮罩消失（接受，無法阻止）
- Chrome 重啟後，若模式仍在進行中 → 自動恢復（Sleep Mode 根據時間判斷，其他模式重置）
- 睡眠模式解鎖密碼錯誤 → 3 次後鎖定 1 分鐘
